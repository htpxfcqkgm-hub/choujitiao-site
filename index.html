关于我们

全家桶工作室是一个小规模的独立创作团队，专注用原生 Web 技术做轻量、即开即玩的小游戏。

我们是谁

全家桶工作室（Bucket Family Studio）是一个由几名成员组成的独立创作团队。我们没有办公室，也没有发行商，项目都是在业余时间一点点做出来的。团队负责从玩法设计、代码实现、美术到文案的全部环节。

我们做什么

我们做的主要是浏览器里的小游戏：不需要下载、不需要注册、打开网页就能玩。目前已上线的作品包括：

  • 蛋仔鸭鸭气球：充气上升、接星星躲障碍的休闲小游戏。
  • 米皮糖小摊：熬糖浆、擀米皮、卖米皮糖的放置经营游戏。
  • 米皮糖小摊 · 怀旧版：回归最初三步循环的复古版本。
  • 酱味大鸡：竖屏自动射击小游戏。
  • 氧气 · 怕你太累了：左右移动接住溺水者的救援小游戏。

我们怎么做

技术上，我们尽量不使用框架和引擎，用原生 HTML、CSS 和 JavaScript 完成全部功能。这样做的好处是页面轻、加载快、在低端设备上也能运行。代价是很多基础设施要自己写，但从长期看，我们对每一行代码都更清楚。

在美术和文案上，我们使用人工智能作为辅助工具来生成草稿和参考，但最终的风格统一、细节调整和取舍都由团队成员完成。关于这一点，我们在版权声明里有明确说明。

这个网站是什么

这个网站是工作室的作品集和开发日志。在这里你可以找到我们所有的游戏入口，也可以读到我们在开发过程中遇到的问题、做出的取舍和一些关于独立开发的思考。我们希望通过这些文字，让对网页游戏开发感兴趣的人少走一点弯路。

Who we are

Bucket Family Studio is a small independent team of a few members. We have no office and no publisher; every project is built in spare time. The team covers gameplay design, engineering, art and writing end to end.

What we make

We build small browser games: no download, no sign-up, just open the page and play. Current releases include:

  • Eggy Duckie Balloon: a casual game about inflating, catching stars and dodging obstacles.
  • MipiTang Stall: an idle management game about boiling syrup, rolling dough and selling candy.
  • MipiTang Stall · Classic Edition: a retro version that keeps only the original three-step loop.
  • Big Saucy Chicken: a portrait auto-shooter.
  • Oxygen · Afraid You're Too Tired: a rescue game about catching people as they sink.

How we work

On the technical side, we avoid frameworks and engines wherever possible and build everything with native HTML, CSS and JavaScript. The payoff is a light page that loads fast and runs on low-end devices. The cost is that we write a lot of infrastructure ourselves — but in the long run we understand every line we ship.

For art and copy, we use AI as an assisting tool to generate drafts and references, but final style consistency, detail work and trade-offs are made by team members. Our copyright notice states this explicitly.

What this site is

This site is our portfolio and dev blog. You can find links to every game here, along with notes on the problems we ran into, the trade-offs we made and some thoughts on indie development. We hope these posts help others interested in web game development avoid a few detours.

我们最希望收到的反馈

  • Bug 报告：请尽量说明使用的设备、浏览器版本，以及复现步骤。附上截图会非常有帮助。
  • 玩法建议：哪一步让你觉得无聊，哪个系统你完全没用到。具体的体验描述比“好玩/不好玩”有用得多。
  • 合作与转载：请在邮件中说明用途、渠道和范围。

我们通常会在 2–3 个工作日内回复。由于团队规模很小，如果回复慢了一些，还请见谅。

Feedback we find most useful

  • Bug reports: please include your device, browser version and reproduction steps. Screenshots help a lot.
  • Gameplay suggestions: which step felt boring, which system you never touched. Specific experience descriptions are far more useful than “fun / not fun”.
  • Collaboration and reposting: please state the purpose, channel and scope in your email.

We usually reply within 2–3 business days. The team is small, so please bear with us if it takes a little longer.
